# UI/UX Review

Evaluate the interface against the target user's task and context, not personal taste.

## Workflow

1. Identify primary user, goal, environment, device, and critical journey.
2. Walk the journey from entry to completion, including loading, empty, error, offline, permission, and recovery states.
3. Review hierarchy, labels, affordances, feedback, consistency, cognitive load, and prevention of irreversible mistakes.
4. Check keyboard use, focus order, contrast, scalable text, semantic structure, touch targets, and non-color cues as applicable.
5. For AI experiences, show system status, uncertainty, source provenance, editable inputs, safe confirmation, and a path to correct or report bad output.
6. Rank issues by user impact, frequency, and implementation effort.

Do not recommend visual polish that obscures a broken journey. Tie each finding to observed evidence or a recognized usability principle.

## Output

Lead with the top three issues. For each finding include location, user impact, evidence, recommended change, priority, and an acceptance check. Note what already works well only when it should be preserved during changes.
