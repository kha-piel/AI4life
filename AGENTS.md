# AI4Life Skills

Project skills live in `.ai4life/skills/<skill-name>/SKILL.md`.

Before work that clearly matches a skill description, read that skill's complete `SKILL.md` and follow it. Load only the skill or skills relevant to the current request; do not run the full lifecycle for every task.

For an end-to-end hackathon project, use this default sequence when each stage is relevant:

`problem-framing → research → ai-literacy → tool-selection → critical-thinking → architecture → rapid-prototyping → model-evaluation → debugging / ui-ux-review → security-privacy → pitch-review`

When time is limited, prioritize:

`problem-framing → tool-selection → critical-thinking → rapid-prototyping → model-evaluation`

User instructions and the actual project state take precedence over this default sequence.
